## Source Sans Pro

The bundled Source Sans Pro webfonts are copyright Adobe Systems Incorporated
and are distributed under the SIL Open Font License, Version 1.1. They are the
same v14 latin-ext files used by the referenced Nginx Proxy Manager v2 frontend
(regular and bold); the regular file is also assigned to CSS weight 600 to
avoid an unreadable synthetic semibold.

The font files are vendored so the UI makes no request to an external font CDN.
