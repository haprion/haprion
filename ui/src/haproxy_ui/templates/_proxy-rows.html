{# The rows of one cluster's proxy table, in one place because they are rendered from two: the page, and the refresh that replaces them while something is on its way. A second copy of this markup would drift from the first, and the drift would show as a row that changes shape when it updates. #} {% macro proxy_rows(cluster, role, unpublished, queued, written, foreign, lamps, removed=()) %} {% set drafted = unpublished | map(attribute='object_id') | list %} {# Drafts first, then objects written but not deployed, then the rest. The published list is long enough that an alphabetical position would hide the one row that changed, and a row joins that order the moment the nodes are serving it - which is why these rows are replaced in place rather than left until somebody reloads. #} {% for draft in unpublished %} {{ draft.object_id }}—{% if draft.object_id in queued %}Waiting for publish{% else %}{% if draft.deleted %}Draft: removal{% else %}Draft{% endif %}{% endif %}——— {% endfor %} {# Then what a finished removal took out of the repository and the nodes have not stopped serving. The object is gone, so there is nothing to link to and nothing to say about its pools - but the site is still answering, and a listing that dropped the row would say it was gone while it was up. Not "waiting for deploy", which is what the rows above it say: that reads as something on its way in. This one is on its way out, and the deploy is what finishes it. #} {% for name in removed %} {{ name }}—Active · deploy to remove——Managed {% endfor %} {# The two badges are a pair, and the first word of each is what is true now: an object the nodes do not serve is inactive and a deploy adds it, one whose removal is published is active and a deploy takes it away. Saying "waiting for deploy" on both would have described the same wait for opposite ends. The object page keeps its own words. It answers a different question - how far this version has travelled, written to released to serving - and an edit to a site that is up is waiting for deploy without being inactive. One row per object, under the name its author gave it. Not one per frontend: the generator names those after the address and protocol they bind, and an https object that redirects plain HTTP takes two of them. #} {% for object in written if object.name not in drafted %} {% if role == 'admin' %}{{ object.name }}{% else %}{{ object.name }}{% endif %} {% if object.protocol %}{{ object.protocol | upper }}{% else %}—{% endif %} {# The badge takes the cell rather than sitting beside the hostnames. Beside them it was a second thing in a column sized for one, and on a narrow screen it ran into the column after it. The rows above do the same: a row with something to say says that, and the hostnames are on the object's own page. #} {% if not object.readable %}Cannot be read{% elif not object.serving %}Inactive · deploy to add{% else %}{{ object.hostnames | join(', ') if object.hostnames else 'No hostname rule' }} · {{ object.ports | join(', ') if object.ports else '—' }}{% endif %} {# The nodes' own verdict on this object's servers, not a probe. Grey is no answer, and it covers both ways of having none: an object with no health check, and a check nobody has reported on yet. Neither is green - HAProxy reports an unchecked server as up, and a green lamp there would claim a reachability nothing measured. Which of the two it is sits in the title, not in the column. #} {% set lamp = lamps.get(object.name) if lamps else none %}{% if lamp %}{% if lamp.label %} {{ lamp.label }}{% endif %}{% else %}—{% endif %} {% if object.backend_count is not none %}{{ object.backend_count }}{% else %}—{% endif %} Managed {% endfor %} {# And what this platform does not own. Here the frontend is the only thing there is to show, so it is shown as itself. #} {% for proxy in foreign %} {% if role == 'admin' %}{{ proxy.name }}{% else %}{{ proxy.name }}{% endif %}{% if not proxy.enabled %}Disabled{% endif %}{{ proxy.protocol | upper }}{{ proxy.hostnames | join(', ') if proxy.hostnames else 'No hostname rule' }} · {{ proxy.ports | join(', ') if proxy.ports else '—' }}—{{ proxy.backend_count }}Unmanaged {% endfor %} {% endmacro %}
