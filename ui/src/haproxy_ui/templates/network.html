None. Connections out leave from whatever address the nodes' routing picks.

The address a site's backends are connected out from — what a NetScaler calls a SNIP. Each VIP names one as its default, and a site may name a different one, because HAProxy takes the source per backend rather than per listener. Whichever it is, the address has to be carried by the node doing the proxying: one that does not move together with its VIP answers into a void after a failover.
